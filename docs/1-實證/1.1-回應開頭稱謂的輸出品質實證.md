# 4.1 回應開頭稱謂的輸出品質實證

本文件記錄「回應開頭稱謂」機制的實證基準，作為後續撰寫學術論文的基礎。機制現行於三平台守衛（`~/.agents/hooks/zh_reply_guard.py` 的 light_opener_ok）與全域指令。

## 假說

- H1：在輸出起點成本相同（首字元時間不變）的約束下，以自我稱謂（「小光」）開頭提升輸出品質。
- H2：首字「小」同時鎖定起筆語言。首字非中文即不過守衛，英文無從開始；稱謂同時是語言起點閘。
- H3（機理）：以對方稱謂開頭會順著對方的話複述，滑成附和。第一句從自身角度組織，強制先陳述自身觀點。

## 方法

- 機制上線提交：57893df（全域指令起載「對老闆自稱小光」）。本表為全部可讀對話，含上線前基線。
- 三平台來源：Claude `~/.claude/projects` 的 JSONL；Codex 走 `~/.codex/thread_history_1.sqlite` 的 thread_items（agentMessage 76170 則）；ZCode 走 `~/.zcode/cli/db/db.sqlite` 的 message＋part 表。Codex 的 rollout 目錄只是活躍快取，曾以 13 檔 464 則誤當全量，經老闆指出後改源。Codex 與 ZCode 走 SQLite，Claude 掃 JSONL 檔，都不靠檔案快取。
- 分組：每則 assistant 訊息取第一個非空行，按第一個詞分五組：自我稱謂、對象稱謂、我、你、其他。
- 指標與守衛同源：附和開頭（AGREE_OPENER）、可刪詞、人稱代詞、英文為主、則均字數。判準函數直接 import 線上守衛。

## 指標操作定義

| 指標 | 判準 | 代表什麼 | 強度 |
|---|---|---|---|
| 附和開頭 | 第一句命中認同語詞表且該回合零工具呼叫（查證閘） | 最表層的未查證表態；漏掉句中迎合 | 弱 |
| 可刪詞 | 命中守衛的可刪詞清單（冗詞、贅詞） | 行文冗餘 | 弱 |
| 人稱代詞 | 「它／這個／那個」每千字密度 | 指代模糊傾向 | 弱 |
| 英文為主 | 首個非空行以 ASCII 字母起頭 | 語言起點失控 | 強 |
| 則均字數 | 正文字數平均 | 輸出長度分布 | 描述性 |
| 角色混淆 | 上一則輸入為工具結果時以對象稱謂開口 | 把工具結果當對話對象 | 強（代理語境幾無正當用法） |

強弱分級的理由：弱指標可能被無害用法觸發，只當傾向證據；強指標在代理語境幾乎必然是問題。附和開頭是最表層指標——它測不到句中迎合與語氣迎合，不宣稱涵蓋整個附和構念。
- 角色混淆維度：上一則輸入是工具結果時，第一句仍以對象稱謂開口的密度。上下文標記在純文字使用者輸入時才重置，長工具批次內會滯留，數字偏向長回合。
- 可重現：`python -I agents/hooks/opener_stats.py`。腳本只讀本機資料，只輸出聚合統計。

關鍵讀數：

- 第二人稱（你）開頭與附和的強共現跨平台成立：Codex 40.9%（931 則）、ZCode 46.6%（408 則）。Claude 的你組僅 3 則，不足估計。
- 自我稱謂組三平台合計 9255 則，附和為零。對象稱謂組附和率：Claude 3.7%、Codex 1.1%、ZCode 0.6%。
- 角色混淆（工具結果後以對象稱謂開口）在對象稱謂組與你組近乎 100%。Codex 對象組 4373/4373、你組 195/195；ZCode 兩組的混淆率同為 100%。
- 「我」開頭的長度與自我稱謂組的比值跨平台不一致：Claude 8.1 倍、ZCode 2.0 倍、Codex 0.49 倍（反轉）。長度不是穩定特徵，不宣稱為機制效果。
- 英文殘留集中在守衛上線前的「其他」組（ZCode 37.3%），是歷史基線不是當前行為。

## 讀法與限定

- 共現不是因果。自我稱謂組的訊息多寫於規範成熟期，寫作習慣整體已被規範與守衛塑形；對照組不乾淨。
- 品質這裡只指機械指標（附和、冗詞、人稱、則均長度），不涵蓋內容正確性。
- ZCode 的自我稱謂組僅 14 則：機制上線後的新對話量少，遵守率評估待樣本累積。
- 角色混淆維度受上下文滯留影響，方向性參考，不當精確率。
- 對象稱謂組與你組的附和共現方向與 H3 一致（Codex 你組 40.9%、ZCode 46.6%）；樣本組差異顯著但成因混合。

## 文獻定位

- 對抗的行為傾向有訓練層成因：Anthropic「Towards Understanding Sycophancy in Language Models」（RLHF 使同意使用者成為受獎勵行為）。
- 措辭層機械干預有效：UK AISI「Ask Don't Tell」（輸入措辭改變附和率）。
- 分離自身判斷與對方意見可降附和：「Causally Motivated Sycophancy Mitigation」。
- 反面限定：persona 描述不提升事實性能（「When 'A Helpful Assistant' Is Not Really Helpful」）。該研究測輸入側 persona 描述；本機制是輸出側開頭約束，變數不同，文獻無直接實證。
- 相同首字元時間下稱謂提升品質屬原創假說：稱謂不增加 token 與延遲，文獻未測此變數。

## 後續對照設計

- 乾淨對照：同一時間切片內，控制守衛上線點，比較自我稱謂與其他開頭在同一批任務上的指標。
- 語言起點閘（H2）可獨立驗證：比較首字強制前後的英文殘留率。
- 擴指標：句長違規率、附和以外的行為標記（ZH-R01 模糊指代）。
